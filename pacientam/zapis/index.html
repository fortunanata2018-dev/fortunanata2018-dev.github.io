Как записаться

Сейчас доступны два способа записи на платный приём: по телефону и лично в регистратуре.

По телефону

При обращении назовите услугу или специальность врача.

Для редактора — не для публикации: До публикации обязательно добавить подтверждённый телефон платной регистратуры с кнопкой звонка, дни и часы ответа. Указать порядок действий, если пациент не дозвонился.

В регистратуре

Адрес диспансера: Сыктывкар, улица Куратова, 66.

Адрес и информация о посещении

Для редактора — не для публикации: Добавить вход, этаж, часы записи и необходимые документы.

Для редактора — не для публикации: Согласовать форму обращения, MAX или другой канал, ответственного сотрудника, время ответа и подтверждение записи. Раздел не публиковать как действующий способ до подключения.

Для редактора — не для публикации

Синим выделены рабочие замечания. Этот блок будет убран из версии для пациентов.

  • Подтвердить телефон и дни платного приёма.
  • Обсудить с главврачом электронную запись и обратную связь: форма, MAX, ответственный сотрудник, срок ответа, защита данных.
