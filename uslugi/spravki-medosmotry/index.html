Обследование и оформление

Для разных заключений состав обследования различается. Некоторые этапы могут проходить в других учреждениях.

Для редактора — не для публикации: Для каждой справки описать последовательность этапов, адреса, документы, сроки и полную стоимость; поставить прямые ссылки. Не обещать комиссию по одному адресу.
